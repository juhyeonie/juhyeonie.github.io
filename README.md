# juhyeonie.github.io

Forwards case variants of the Little Frames link (GitHub Pages paths are case-sensitive) to
**[juhyeonie.github.io/Little-Frames](https://juhyeonie.github.io/Little-Frames/)**.

- `little-frames/index.html`: forwards the lowercase link, with the same link-preview tags as the site
- `404.html`: forwards any other spelling of `/little-frames`
